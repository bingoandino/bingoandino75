# Dinámicas de Bingo Andino 75

Dirección: https://bingoandino75.com/dinamicas/

## Instalar

En Chrome de Android, pulsa **Instalar app**. Si el navegador todavía no ofrece la ventana de instalación, usa su menú ⋮ → Instalar aplicación o Agregar a la pantalla principal. En iPhone, usa Safari → Compartir → Agregar a inicio.

La app puede abrir su interfaz sin conexión; generar dinámicas, consultar ganadores y entregar cartones requieren internet y acceso del administrador por código de correo.

## Dinámicas

El botón **Anuncio antes de las dinámicas** prepara el mensaje con el premio de un cartón gratis y el límite de una victoria por semana. Los tipos incluyen adivinanzas, trivia, palabras desordenadas, acertijos y fotos de objetos en casa. Las fotos se reciben y revisan manualmente en WhatsApp; la app prepara el reto y sus criterios, no lee las respuestas del grupo.

## Entregar el premio

1. Abre **Ganadores**, ingresa como administrador y comprueba que las ventas del sorteo actual estén abiertas.
2. Ingresa nombre, cédula, teléfono móvil y banco. Revisa los datos y confirma la entrega.
3. El sistema selecciona un cartón libre, lo registra aprobado con monto cero y guarda el ganador en el historial del servidor.
4. Usa **Compartir ganadores de hoy** para revisar y compartir nombres y números de cartón. No se incluyen datos de Pago Móvil.

Cada cédula puede recibir un premio de dinámica por semana, de lunes a domingo, con hora de Venezuela. El historial sobrevive a los reinicios del sorteo. Los premios no cuentan como compras para el ranking.

Si una entrega no se confirma por un corte de conexión, pulsa **Reintentar entrega pendiente** con los mismos datos. El identificador de la operación permite recuperar el resultado sin entregar otro cartón.
